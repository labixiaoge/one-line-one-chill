## About

This entry is a single line of horror: one sentence, under 200 characters, that has to frighten a reader in one breath. A gravedigger, a burial, a headstone — and a name that should not be there yet, dated today. The scare is earned, not announced: no gore, no mirror, no doll, no basement, and the dread outlasts the line because the date is today. The entry program (`main.ts`) writes exactly that sentence to `/output/entry.txt`, deterministically, with no randomness, no clock, and no network.

## Entry

> The gravedigger at my father's burial asked me to check the headstone, and my name was already carved beneath his, with today's date.
